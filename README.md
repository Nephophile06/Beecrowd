# Beecrowd Problem Solutions in C/C++
This repository contains my collection of problem solutions from [Beecrowd](https://www.beecrowd.com.br/). It is intended to document my learning journey and share solutions for educational purposes.

## 📌 About the Repository
- All problems are solved using **either C or C++**.
- Files are named using the format: `problem 'problemNumber' - 'problemName'`
- There is no folder structure; all files are stored at the root level for simplicity.
- Each file contains a clean and readable implementation, often with comments for better understanding.

### 🗂 Example File Naming Convention

```
problem 1000 - Hello World
problem 1001 - Simple Sum
...
```

## 🔍 Topics Covered
- Basic Input/Output
- Conditionals and Loops
- Functions
- Arrays and Strings
- Basic Data Structures
- Math and Ad-hoc
- Random problems

## 💡 How to Use
If you're learning programming or preparing for competitive programming:
1. Browse by file name (which includes problem number and name).
2. Open the file to study the logic.
3. Try solving it yourself first before referring to the solution.
